FAQs

Kya file bhejne ke liye login chahiye?

Nahi — customer ko koi login nahi chahiye. Bas file choose karein aur bhej dein.

Kaun si files bhej sakte hain?

PDF, Word (.doc/.docx), Excel (.xls/.xlsx), PowerPoint (.ppt/.pptx), JPG aur PNG — har file max 25MB.

Print kab niklega?

File bhejte hi dukaan ke dashboard par khul jati hai (Auto-Open) aur Auto-Print ON ho to foran print ho jati hai.

Kya ye mobile par chalta hai?

Ji — ye page phone par bhi waisa hi chalta hai, gallery ya camera se photo seedha upload kar sakte hain.
